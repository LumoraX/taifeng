Taifeng compaction map

One conversation, step by step: an image, a huge tool output and a PDF come in, the context fills up, compaction moves things out to disk, and the model reads them back.

Example setup: 32k context window, soft limit lowered to 52% (soft_limit_ratio=0.52; the default is 0.85), compressors = [offload, image evict, handoff] with offload and image eviction given a priority above handoff and a shared workspace, and file_read(attach_images=True). All of that is opt-in; the default is handoff + sliding at 85%.
