# ADR 0129：工作区原子写与一致性检查

状态：Accepted

Amends #0113

## 决策

固定临时路径能被预先放置的链接导向工作区外，失败残留与并发写共享临时文件也违反原子写承诺。
LocalWorkspaceFS 在目标父目录创建独占随机临时文件，失败尽力清理，每个调用分别原子替换目标。
并发写允许最后完成的版本生效，不引入CAS或新的协议方法。
删除最终符号链接只删条目，父路径仍检查边界；读写及 metadata/resolve 继续跟随最终链接并检查边界。

在 taifeng.testing 公开工作区行为一致性检查，不依赖 pytest，不假设本机文件路径。
链接创建与物理失败注入不在7成员协议内，由后端自己的测试验证。
本机默认实现不承担敌对进程持续替换目录造成的TOCTOU隔离，真正沙盒由宿主实现协议。
