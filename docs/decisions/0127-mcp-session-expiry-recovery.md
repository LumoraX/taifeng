# ADR 0127：MCP 会话失效的有限恢复

状态：Accepted

## 决策

带会话的 404 重新 initialize，受锁保护且一次请求最多重试一次。原 POST 被直接拒绝才可重试；响应续传 404 时已可能执行的工具调用不得重放。恢复中的新请求与推送流等待锁；握手内的服务端请求应答不等待同锁，但必须匹配来源会话，避免死锁与旧应答串会话。GET 推送同样恢复并重置旧 cursor；工具集变化走原有通知。按已支持的 2025-06-18 规范修复，不扩大协议版本清单。
