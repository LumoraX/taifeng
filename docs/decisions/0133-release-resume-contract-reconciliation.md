# ADR 0133：发行线恢复契约的合流

状态：Accepted

日期：2026-11-10

Supersedes #0120

## 背景

远端发行线的 ADR 0117（部分核销防重与保留挂起的停止生成）与本地 ADR 0117–0121
并行演进，形成编号冲突和人工混合核销语义冲突。旧 ADR 保留原文，以文件名区分。

## 决策

保留远端已发布的严格规则：人工 Resume 含任何已核销项时整次拒绝
request_already_resolved。先验证完整 ID 集合，未知与空请求仍明确拒绝。
纯到期哨兵仅过滤已核销项；空交集沿用本地 already_resolved 终态，防止订阅悬挂。
保留本地提交终态、取消准入与回写所有权。根中止同时发 resumed=False 与 aborted=True，
兼容两条发行线的消费者。非中止不新增 aborted 字段。
preserve_suspension=True 不登记回写后的挂起丢弃；已有默认丢弃请求不被后续保留请求覆盖。

## 验证

root、call_skill 叶子和直接 spawn 同时覆盖重复与混合核销整次拒绝；
回写屏障覆盖默认取消与保留挂起取消。全量 sim 门禁与真实模型能力矩阵作为发行门禁。
