# ADR 0117：部分核销防重与保留挂起的停止生成

- 状态：采纳
- 日期：2026-10-21

## 问题

部分 Resume 后 record 仍活跃，既有 resolver 接受原 record 中已核销项，会再次执行工具。
宿主检查 pending 后再发 CancelTurn 也存在竞态：actor 处理时目标可能已经挂起，默认会丢弃待办。

## 决策

复用已有 request 级持久输出推导，不引入新的锁服务或业务回执到内核。
在 root、child 和 spawn 的计划生成之前验证人工决定不含已核销项；整次拒绝混合集合。
到期哨兵继续只处理未核销集合。并发的 record 在飞守卫维持原机制。

CancelTurn 增加默认 False 的 preserve_suspension。显式 True 时 actor 只停止在途执行，
目标已挂起或结束时保留状态并发日志。默认旧行为不变；审计模式本来只取消 active target。
该字段采用默认值不序列化，保持既有默认提交的序列化契约。

## 边界

已有工具输出是已核销证据；外部动作已发生但输出未持久化仍是未知结果，不能推导严格一次执行。
宿主仍须实施持久认领、授权与未知结果策略。内核不引入租户或宿主业务概念。

根 thread 的系统 abort 没有后续 turn，Resolved 事件增加可选 aborted=True，作为明确操作结论。
不为没有采样的中止制造成功 turn，审计模式和普通模式一致。
