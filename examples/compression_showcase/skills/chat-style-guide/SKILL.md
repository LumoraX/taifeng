# 健谈风格速查

本 skill 仅作为 `chatty-assistant`（composite entry）的 `child_skills` 占位，
满足 SkillDefinition 校验"composite 必须声明 child_skills"的硬约束。

**不会被实际调用**，chatty-assistant 的 prompt 已明确禁止 call_skill。

## 内容（占位文档，不重要）
- 长回复 = 至少 4 段
- 每段 = 4–6 句
- 段落配小标题（## / ###）
- 偏好举例 / 类比 / 延伸阅读
